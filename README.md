## 👨‍💻 About Me

I am an aspiring data scientist who learns by building complete projects instead of stopping at notebooks. My latest project takes a dataset through EDA, preprocessing, model comparison, and tuning, then serves the trained model through a validated FastAPI backend and a web interface.

I care about **checking my own results**. When an API prediction looked wrong, I investigated it instead of trusting the response. When tuning barely improved my model, I documented that honestly.

## ⭐ Featured Project

### 🚗 [CarDekho Used Car Price Prediction](https://github.com/Rishit-Vish/CarDekho-Used-Car-Price-Prediction)

An end-to-end machine learning project that estimates used car selling prices from vehicle specifications.

| | |
|---|---|
| **Problem** | Supervised regression: predict a used car's selling price |
| **Best model** | Random Forest Regressor (best of 5 models compared) |
| **Results** | Cross-validated R² **0.864** · Held-out test R² **0.928** · Test MAE ≈ **₹96k** |
| **What I built** | EDA → preprocessing pipeline → model comparison → tuning → FastAPI backend → web interface |
| **Highlight** | Investigated and validated a notebook-vs-API prediction mismatch (documented as a case study) |
